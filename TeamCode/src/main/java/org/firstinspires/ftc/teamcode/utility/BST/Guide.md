# 跑打算法简化版：取消炮台、仅径向补偿的解析求解

## 一、简化假设

在上一版解析解（R-BST）的基础上，进一步做如下简化：

1. **取消独立炮台**：底盘发射口始终指向球门方向，因此无需计算炮塔水平旋转角 $\phi$。
2. **忽略横向相对运动**：只考虑机器人速度在“机器人—球门”连线方向上的分量，忽略切向分量对弹道的影响。
3. **目标静止**：球门固定不动，相对速度完全由机器人运动引起。
4. **已知静止标定模型**：
    - 射程模型（水平飞行距离与滞空时间的关系）：
      $$
      D(t) = a t + b
      $$
    - 飞轮速度模型（飞轮转速与滞空时间的关系）：
      $$
      S(t) = c t + d_0
      $$
      其中 $a, b, c, d_0$ 为线性回归得到的常数。

## 二、变量定义

- $d$：当前机器人到球门的直线距离（沿连线方向，单位：米）。
- $v$：机器人速度在连线方向的分量，**规定靠近球门为正，远离为负**（单位：m/s）。
- $t$：球的滞空时间（待求，单位：s）。
- $D(t)$：静止标定下，滞空时间 $t$ 对应的水平射程（米）。
- $S(t)$：静止标定下，滞空时间 $t$ 对应的飞轮目标转速（RPM）。

## 三、核心推导

### 3.1 建立补偿方程

机器人以速度 $v$ 沿连线方向运动。球从发射口射出时，具有两部分水平速度：
- 球相对机器人的水平速度（由飞轮提供），其平均效果使球在时间 $t$ 内相对机器人飞行 $D(t)$；
- 机器人自身速度 $v$，使球在相同时间内额外获得沿连线方向的位移 $v t$。

因此，球相对地面在时间 $t$ 内的总水平位移为：
$$
D_{\text{ground}}(t) = D(t) + v t = a t + b + v t
$$

为了命中距离为 $d$ 的球门，该位移必须等于当前距离：
$$
a t + b + v t = d
$$

### 3.2 解出滞空时间

整理得：
$$
(a + v) t = d - b
$$

因此：
$$
\boxed{t^* = \frac{d - b}{a + v}}
$$

### 3.3 计算飞轮速度

将 $t^*$ 代入飞轮速度模型：
$$
\boxed{S^* = c \cdot t^* + d_0 = c \cdot \frac{d - b}{a + v} + d_0}
$$

### 3.4 发射方向

由于取消了炮台，底盘发射口始终指向球门，因此**无需计算水平旋转角**。只需保证底盘已对准球门即可发射。

## 四、边界条件与异常处理

| 条件 | 物理意义 | 处理方式 |
|------|----------|----------|
| $a + v \le 0$ | 机器人远离速度过大，或射程增长太慢，无法命中 | 放弃发射，输出“超出射程” |
| $t^* \le 0$ | 目标过近或模型截距异常 | 放弃发射，输出“目标过近” |
| $d - b < 0$ | 距离小于模型截距，通常因标定误差 | 可将 $b$ 视为 0，或截断到最小距离 |
| $S^*$ 超出飞轮可控范围 | 所需转速过高/过低 | 限制到最大/最小转速，或放弃 |

## 五、算法流程（伪代码）

```java
// 输入：d 当前距离，v 径向速度（靠近为正），robotTheta 底盘朝向，goalAngle 球门绝对方位角
// 输出：飞轮目标转速 S，是否可发射

double t = (d - b) / (a + v);

if (a + v <= 0 || t <= 0) {
    return new Solution("超出射程或目标过近");
}

double S = c * t + d0;

if (S < MIN_RPM || S > MAX_RPM) {
    return new Solution("飞轮转速超出范围");
}

// 底盘需已对准球门：检查底盘朝向与球门方向夹角是否小于阈值
double angleError = normalizeAngle(goalAngle - robotTheta);
if (Math.abs(angleError) > ALIGN_THRESHOLD) {
    return new Solution("底盘未对准球门");
}

return new Solution(S, t, true);
```

## 六、与完整版 R-BST 的对比

| 维度 | 完整 R-BST（带炮台） | 简化版（取消炮台） |
|------|---------------------|-------------------|
| 求解方程 | 二次方程 $A t^2 + B t + C = 0$ | **一次方程** $(a+v)t = d-b$ |
| 计算量 | 需判别式、开方 | **仅一次除法** |
| 炮塔角 | 需计算 $\phi$ | **无需计算** |
| 横向补偿 | 可补偿切向速度 | **忽略切向速度** |
| 适用场景 | 带独立炮塔的机器人 | 底盘直接瞄准、发射口固定的机器人 |
| 精度 | 高（考虑二维速度） | 中（仅径向补偿，横向误差未修正） |

## 七、结论

在取消炮台、仅考虑径向速度分量的简化场景下，跑打公式退化为一个**极其简洁的一次方程**：

$$
\boxed{t^* = \frac{d - b}{a + v}}
$$

$$
\boxed{S^* = c \cdot \frac{d - b}{a + v} + d_0}
$$

该公式计算量几乎为零，非常适合在 FTC Control Hub 上以极高频率运行。只要底盘能可靠对准球门，并且横向速度分量较小（或可通过底盘旋转自然抵消），该简化算法即可提供令人满意的移动射击精度。

**工程建议**：若横向速度较大，可考虑在底盘旋转对准时加入前馈补偿，或恢复炮台自由度以使用完整 R-BST 算法。

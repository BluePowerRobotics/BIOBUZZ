### 自动瞄准
- 瞄准状态下，底盘自动转向瞄准球门方向
- 此时一操右摇杆失效，有头时左摇杆前后控制前进后退，左摇杆左右控制底盘绕球门旋转；无头时先旋转到有头再按有头控制。
- 根据定位位姿计算与球门的距离，线性回归得到发射速度
- 控制飞轮精确达速后发射

## 自动
### 初始固定路径
先吃固定球，然后前往hive初始抬升侧

### 自动发射

### 自动停车
剩余时间一定时开始停车，已实现
### 完整状态机
- START -> 进入LAUNCH_AND_FIRST_EAT
- LAUNCH_AND_FIRST_EAT 执行预载球发射，初始吃球和前往hive初始抬升侧
  - 结束后-> 进入LAUNCH
- LAUNCH 前往当前记录的抬升侧所对发射位姿，完成后根据MT1观测hive状态判断：
  - 该侧抬起 -> 发射，进入WAIT_CELL
  - 该侧未抬起或为UNKNOWN（未检测到） -> 切换抬升测为对侧，进入EAT_CELL
  - MIDDLE -> 等待
- WAIT_CELL 等待一定时长
  - 若变为MIDDLE或UNKNOWN -> 切换抬升侧为对侧，进入EAT_CELL
  - 若不变且达到时长 -> 进入EAT_CELL
- EAT_CELL 用视觉自动吃面前的球，吃完后前往当前抬起位置
  - 结束且有球 -> 进入LAUNCH
  - 结束且无球 -> 进入EAT_CELL
- 以上任意状态中剩余时长达到阈值 -> 进入PARK
- PARK 停车，结束

# 开题前讨论

上赛季prototype阶段期间，队员提出了许多新颖的想法，但由于责任分工与后续工作不明确，队伍陷入了各方案优劣的口头争论中，而几乎没有推进prototype制作进度，最终导致很多方案未能来得及实现

因此，在BIOBUZZ开题前，全体队员再次反思了之前prototype阶段的问题，一致同意了两条原则：
- **用数据说话**：一份真实的实验数据，其价值远大于几小时的凭空讨论。所有方案提出后，都应该先落地prototype做出实机，再通过实验收集数据，最后基于数据讨论方案的优劣。
- **谁提出，谁负责**：所有队员都参与prototype制作，但每个prototype的进度由它的**提出者**负责。在约定的期限之前，方案的提出者必须向队伍提交实验数据，以证明自己方案的优越性，否则该方案将被视为不可行

# 9/13开题会议

上赛季已经获得了炮台+单飞轮的数据，以该方案为基线，队员在开题会议上提出了以下方案：

## 1. 四球并发

用一个长条飞轮（drum）实现四个球同时发射
理论发射时间可减至1/4

理论有效射区：

- 自cell张开左右各54度（仅考虑宽度），约4块地垫
- 自cell张开左右各15度（考虑四球射程误差），约2块地垫

优越性目标：得分期望，射区占比，发射时长至少一项最优

存在电机负载过大、球体碰撞发散及射程差的风险。
​​

## 2.四球抬升​​

采用侧面抬升管状结构，向花筐内同时扔4个球

优越性目标：得分效率优于最优的发射方案

## 3.单球夹取

用外挂机械夹爪抓取nectar，无需预留大球进入车内空间。

可行性目标：能稳定抓取即可

## 4.windmill推球

用windmill推球，可实现大小球兼容

优越性目标：得分期望，射区占比，发射时长至少一项最优

# 验证计划​​

​​设定验证时间节点​​：所有关键方案的原型机必须在10月1日前完成初步测试并获得数据，否则不再考虑后续开发。

​​分配专项测试任务​​：针对不同方案的核心技术难点，由方案的提出者负责对应的原型机制作与验证工作。


# 后续计划

- 并发成功：
  - 夹取成功：采用并发+夹取
  - 夹取失败：只采用并发
- 并发失败：
  - windmill推球成功：
    - 夹取成功：采用windmill推球+夹取
    - 夹取失败：只采用windmill推球
  - windmill推球失败：
    - 抬升成功：采取单发+抬升
    - 抬升失败：
      - 夹取成功：采用单发+夹取
      - 夹取失败：只采用单发

# 9/22
经计算，若使用四球并发，飞轮质量将达到1.1kg，加速需要约1s时间。根据上赛季经验，该时间会极大浪费比赛时长，并增大发射过程中受到干扰的可能性。因此，最终决定放弃4球并发方案，但继续考虑测试更保守的双球并发方案。
# 9/26
经实验，大球抬升的得分效率低于发射的得分效率，因此最终决定放弃四球抬升，改为大小球双发射口。
经计算，大小球双发射口的得分效率约为双球并发的1.1倍，故放弃双球并发方案，考虑大小球双发射口+夹取
